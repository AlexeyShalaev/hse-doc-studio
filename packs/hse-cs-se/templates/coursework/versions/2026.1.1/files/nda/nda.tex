\begin{enumerate}[leftmargin=1.4em, itemsep=5pt]
  \item Не совмещать работу в~НИУ ВШЭ над проектом «\hseProjectName» (далее~---
        Проект) с~работой в~иных организациях (кроме Компании и~НИУ ВШЭ).

  \item Не использовать в~рамках работы над Проектом, не~включать в~состав
        результатов Проекта какие-либо сторонние (в~том числе свои, созданные до
        начала Проекта) исходные коды программ, картинки, тексты, on-line сервисы
        и~любые другие аналогичные материалы, которые могут являться объектом
        исключительного права, без специального согласования с~руководителем
        Проекта от~Компании.

  \item Не передавать другим организациям (включая НИУ ВШЭ, не~включая Компанию)
        и~частным лицам, как во~время работы над Проектом, так и~после окончания
        работы, любые полученные в~рамках выполнения этого Проекта материалы, что
        включает в~себя: блок-схемы и~диаграммы с~архитектурными решениями,
        собственно программные коды, описания API, документацию для разработчиков
        и~администраторов, перечни компонентов и~зависимостей, сведения о~применяемых
        алгоритмах для защиты информации, сведения из~системы отслеживания ошибок
        (bug tracking), результаты нагрузочного и~сценарного тестирования,
        относящиеся как к~подлежащему разработке программному обеспечению, так и~к~уже
        существующему программному обеспечению, в~том числе к~существующим
        коммерческим продуктам и~онлайн-сервисам Компании, независимо от~наличия на~них
        грифа «Конфиденциально» и~подобных (далее~--- Материалы), а~также любую
        ставшую мне известной информацию касательно внутренней деятельности Компании
        (включая порядок организации работы, порядок и~размеры оплаты труда,
        организационную структуру фирмы и~пр.).

  \item Не использовать созданные самостоятельно в~рамках выполнения Проекта
        Материалы в~других разработках за~пределами НИУ ВШЭ. Не~передавать на~сторону
        и~не использовать для других целей любые программные продукты, SDK,
        библиотеки, инструментальные и~отладочные средства, полученные и/или
        используемые в~процессе выполнения Проекта, за~исключением свободного
        программного обеспечения (FOSS), обнародованного и~свободно распространяемого
        третьими лицами под одной из открытых лицензий, список которых приведён
        на~сайте \url{https://spdx.org/licenses}.

  \item Не публиковать программные коды, разработанные в~рамках выполнения Проекта;
        публиковать другие разработанные в~рамках выполнения Проекта Материалы,
        в~том числе в~составе научных публикаций, и~демонстрировать их~в~рамках
        защиты данного Проекта и~иных проектов только после согласования
        с~руководителем Проекта от~Компании.

  \item Вышеизложенные обязательства принимаются мною на~срок всего обучения в~НИУ
        ВШЭ, а~обязательства по~неразглашению Материалов, изложенные в~пунктах
        3--5,~--- на~срок всего обучения в~НИУ ВШЭ и~плюс 3~(три) года после
        прекращения обучения в~НИУ ВШЭ.

  \item Участвовать в~защите Проекта в~НИУ ВШЭ только в~присутствии руководителя
        Проекта от~Компании.
\end{enumerate}
