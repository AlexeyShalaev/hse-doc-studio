% ВАЖНО: \begin{frame}{Заголовок} трактует СЛЕДУЮЩУЮ фигурную группу
% как ПОДЗАГОЛОВОК слайда: `{\small …}` в начале тела молча уедет в
% \insertframesubtitle. Штатный шаблон его хотя бы печатает, а
% самописный без \insertframesubtitle потеряет содержимое НАСОВСЕМ
% (без единой ошибки в логе). Поэтому: (а) не начинайте тело слайда
% с фигурной группы (\begingroup…\endgroup — безопасная замена),
% (б) не переопределяйте frametitle телом без \insertframesubtitle.
