# Командная строка и CI

<p class="hds-lede">Те же проверки, что в Студии шаблонов, есть в командной строке: `hse-doc-studio pack`. Её запускает CI репозитория паков, ей удобно пользоваться агенту в репозитории. Студию шаблонов целиком можно поднять у себя одной командой.</p>

## Локальный запуск

- **Автор паков:** профиль «только Студия шаблонов» в Docker, без входа и проектов: [Студия шаблонов у себя](../deploy/pack-studio-local.md).
- **Разработчик Студии:** `make pack-studio` в рабочей копии репозитория, адрес <http://localhost:3001/pack-studio>, пространство над `packs/` рабочей копии.
- **Своя локальная Студия:** включите раздел в **Настройках** и откройте папку с паками пространством.

## Команда `hse-doc-studio pack`

Работает с папкой паков без Студии и без TeX: `pack lint`, `pack check`, `pack classify`, `pack new-version`, `pack freeze`. Полный список, ключи и коды выхода: [Пак и шаблоны, команда](../reference/pack.md#pack-cli).

Без установки Python команда есть в образе Студии:

```bash
docker run --rm -v "$PWD:/repo" -w /repo ghcr.io/alexeyshalaev/hse-doc-studio:<версия> \
  hse-doc-studio pack check packs
```

## CI своего репозитория паков { #ci }

Проверка на каждый PR это `hse-doc-studio pack check <папка паков> --base <базовая ветка>`: линтер, неизменность выпущенных версий, схемы манифестов, класс невыпущенных версий, файлы сценариев и линтер результата. Упавший сценарий и находки-предупреждения джоб печатает и не падает; падает он на ошибках (в том числе на нарушении формата файла сценария). С `--base` выпущенными считаются версии из `releases.yaml` базовой ветки: PR не может ни убрать, ни пересчитать их записи. Запускайте её в образе Студии той версии, которой пользуются ваши авторы. TeX и секреты не нужны.

Готовый файл CI кладёт команда `hse-doc-studio pack ci init` в корне репозитория паков: `--provider github` (по умолчанию) пишет `.github/workflows/hse-packs.yml`, `--provider gitlab` пишет `.gitlab-ci.yml`. Задача запускает `pack check` в образе Студии той же версии, что команда, на PR и MR с базовой веткой. Ключи и подробности: [Пак и шаблоны, CI репозитория паков](../reference/pack.md#pack-ci). После обновления Студии запустите команду снова с `--force`, чтобы CI взял новый образ.

Статус проверок хостинга Студия шаблонов показывает в панели git, см. [Предложить изменения](propose.md#hosting-checks).
