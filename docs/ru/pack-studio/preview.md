# Предпросмотр и места подписей

<p class="hds-lede">Вкладка «Предпросмотр» собирает документ версии так, как его получит студент: на тестовых данных и в выбранной комбинации (язык, вид работы, состав, руководители). На собранном PDF можно поставить места подписей и метки даты мышкой.</p>

## Сборка

Откройте любой файл внутри версии (манифест, документ, шаблон) и вкладку **Предпросмотр**:

1. **Документ** версии. Документ, которого в этой комбинации нет, помечен «не в этой комбинации».
2. **Тестовые данные**: файл примера или автонабор (ниже).
3. **Комбинация**: язык, вид работы, состав (один автор, команда из двух или трёх), научный руководитель (из ВШЭ, из компании, не указан), консультант, академический руководитель, NDA (если он есть у версии) и первые поля анкеты с выбором или галочкой. **Сбросить комбинацию** возвращает значения набора.
4. **Собрать.** Сборка идёт на раннере, как у проектов: локально встроенный раннер с Docker, на сервере раннеры установки в вашу квоту.

Рядом PDF (**Открыть во весь экран**) и **Журнал**. Та же комбинация на тех же файлах второй раз не собирается, PDF берётся из кэша. Если файлы менялись после сборки, Студия скажет об этом: соберите заново. Одновременно идут не больше двух сборок предпросмотра у человека, сборку можно **Отменить**.

Первая сборка ждёт образ TeX. Если LaTeX упал, первая строка с «!» в журнале указывает место; предупреждения шаблона Jinja идут в журнал строками `[render]`.

## Тестовые данные { #examples }

Автонаборы есть всегда:

- **Обычный**: значения из подсказок и значений по умолчанию полей;
- **Длинные значения**: каждое строковое поле втрое длиннее, так видно переполнение строк титула;
- **Пустой**: только обязательные при создании поля, остальное печатается заглушками.

Свои наборы лежат в `templates/<шаблон>/examples/<имя>.yaml`, вне каталогов версий: их правка не меняет версию и не требует выпуска. Студия их не читает при создании проектов.

```yaml
label: { ru: "Команда, руководитель из компании", en: "Team, company supervisor" }
name: { ru: "Контур согласования действий LLM-агента", en: "An Approval Gate for LLM Agents" }
lang: ru
staffing: team2
authors:
  - { name: "Иванов Иван Иванович", group: "МСПИН261" }
  - { name: "Петрова Анна Сергеевна", group: "МСПИН261" }
supervisor: { name: "Петров Пётр Петрович", position: "доцент", role: company }
meta:
  proposal_stage: "Предварительная"
```

- `lang`, `kind`, `staffing` набор предлагает как значения комбинации, их можно переключить.
- Люди: `authors` (до трёх), `supervisor`, `co_supervisor`, `academic_supervisor`; у человека `name`, `group`, `email`, `position`, `degree`, `role` (`university` или `company`).
- `meta`: значения полей анкеты по их ключам (строки, числа, `true` и `false`).
- Ответы анкет набор пока не задаёт.

## Места подписей { #places }

У удачной сборки переключатель **PDF** и **Места подписей**. Во втором виде рамки слотов подписей лежат на страницах, справа каталог слотов документа.

- Перетащите рамку, чтобы поставить место. Рамка показана в пропорции 3:1: в проекте высота зависит от картинки подписи.
- **Своё место документа** или **Место по умолчанию** слота (бледная рамка с пометкой «по умолчанию»). **Сделать местом по умолчанию** делает место документа общим для всех документов без своего места, **Убрать место документа** возвращает документу место по умолчанию.
- Если в шаблоне есть строки подписи (якоря), новое место встаёт на строку слота и двигается относительно неё. **Привязать к строке** и **Отвязать от строки** переключают это явно. У сборки без строк двигается запасное место.
- Метки даты: двигаются так же, **Метка на строку даты** ставит метку на строку шаблона, **Удалить метку** убирает.
- Места округляются до миллиметра, ширина от 10 до 200 мм, рамка не выходит за лист.

Правки мест пишутся в `version.yaml` точечно: остальной текст и комментарии файла не меняются. Места и метки даты это patch-изменение. У выпущенной версии места только для просмотра. Как места устроены в манифесте: [Пак и шаблоны, заготовки подписания](../reference/pack.md).

Подсказки о местах (за краем листа, место `per_author` на общем документе, узкое место под плашку открепленной ЭП) приходят в панель **Проблемы**.
