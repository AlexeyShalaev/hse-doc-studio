# Профили сдачи

<p class="hds-lede">Профиль сдачи — объявленная паком точка, к которой собирается пакет: состав позиций, подписи и анкеты. Именно его видит кнопка «Упаковать».</p>

Профиль
:   Именованная точка сдачи с описанием и списком позиций. Сколько их и какие — решает шаблон; в приложении это станции рейки «Сдача».

Позиция
:   Документ в составе пакета плюс условия включения: «только командный проект», «только для типа работы», «пропускается, если включён NDA». Студия сама включает и выключает позиции по свойствам проекта — оговорки не мелкий шрифт, а логика пакета.

Подпись
:   Именованный слот (автор, руководитель…) с одним PNG на проект и размещением по документам. Позиция может требовать подписи — без них кольцо готовности не замкнётся.

Анкета
:   Форма, объявленная паком, — например, декларация об использовании ИИ. Из ответов собирается официальный документ пакета.

Кольцо готовности
:   Индикатор «Готово N из M» у точки: что уже собрано, подписано и заполнено, а чего не хватает.

Упаковка
:   Архив с каноническими именами файлов; каждый собранный пакет хранится в «Прошлых сборках» — можно скачать или скопировать путь.

Как это выглядит в работе — на странице [«Сдача и упаковка»](../workbench/submit.md).
