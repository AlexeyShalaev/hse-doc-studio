# Глоссарий

<p class="hds-lede">Термины в том виде, в каком их использует интерфейс. Если на этом сайте слово написано иначе, чем в приложении, — это ошибка сайта: сообщите.</p>

## Шаблоны и структура

Пак
:   Набор шаблонов учебного заведения или программы. Пак объявляет документы, метаполя, правила проверок, анкеты и профили сдачи.

Шаблон
:   Тип учебной работы внутри пака — например, дипломная работа или курсовой проект.

Версия
:   Снимок требований шаблона. Фиксируется в проекте при создании — требования не меняются под вами посреди года.

Тип (прикладная / исследовательская)
:   Формат работы. Меняет состав комплекта: какие документы существуют в каждом типе, объявляет шаблон.

Метаданные (мета)
:   Поля проекта, объявленные паком: тема, группа, руководитель, шифр… Впечатываются во все документы при каждой сборке. Пометка «к сдаче» — поле обязательно до упаковки.

Проект
:   Обычная папка на диске с файлами документов и служебной папкой `.hse-studio/`.

Слаг
:   Короткое имя папки автора в командном проекте (`shalaev`).

Общие документы / `shared/`
:   Общекомандные редакции документов рядом с личными комплектами авторов.

## Документы и сборка

Документ
:   Одна единица комплекта. У документа есть код, статус, свои файлы и своя история сборок.

Собрать / Собрать всё
:   Скомпилировать документ (латex → PDF) / поставить в очередь весь комплект.

Сборка
:   Один запуск компиляции; также вкладка с живым логом.

Движок
:   LaTeX-компилятор; по умолчанию xelatex.

Превью
:   Вкладка с собранным PDF (или HTML-слайдами).

Рядом
:   Режим «превью + редактор» на одном экране.

Код / Визуальный
:   Режимы редактора: сырой LaTeX или визуальный с рендером формул и карточками блоков.

Кастомный документ
:   Свой файл, положенный вместо генерируемого («Заменить на свой файл…»).

Из шаблона — защищён
:   Файл, которым управляет пак: переименовать или удалить нельзя, содержимое обновляется из метаданных.

SyncTeX
:   Связь PDF ↔ исходник: Ctrl+клик прыгает в обе стороны.

## Проверки

Замечания
:   Находки проверок и ошибки сборки — панель и вкладка документа.

Проверки
:   Механизм нормоконтроля: движки + правила из пака.

Правило
:   Одна проверка с идентификатором вида `gost-7.32-2017/page-margins`; см. [«Проверки и правила»](checks-rules.md).

Уровень
:   Серьёзность находки: ошибка / предупреждение / инфо. Переопределяется на находке, документе или проекте.

Соответствие: N%
:   Доля пройденных проверок документа.

`% hse-noqa`
:   Комментарий-исключение: «это замечание я осознанно игнорирую» — виден в диффах.

## Сдача

Сдача
:   Режим рейки: контрольные точки, анкеты, подписи, требования, упаковка.

Контрольная точка
:   Точка сдачи — [профиль](checkpoints.md), объявленный паком: состав пакета, подписи, анкеты.

Кольцо готовности
:   Индикатор «Готово N из M» у точки.

Упаковать
:   Собрать архив пакета с каноническими именами файлов.

Сабмишн
:   Один собранный архив; хранится в «Прошлых сборках».

Анкета
:   Форма, объявленная паком, — например, декларация об использовании ИИ; из ответов собирается официальный документ.

Слот подписи
:   Именованное место подписи (автор, руководитель) с одним PNG на проект и размещением по документам.

Трассировка требований
:   Матрица «требование → где упомянуто» на основе `\req` / `\reqref`.

## История и система

История / История изменений
:   Git-история проекта в `.hse-studio/git/` — отдельная, не ваш репозиторий: автосохранения, именованные версии, диффы, безопасный откат.

Важная версия
:   Именованный снимок («Глава 3 готова»).

Образ
:   Docker-образ служебного сервиса: TeX Live, LanguageTool, Gotenberg, ONLYOFFICE, Ollama.

Провайдер
:   Подключение к облачному ИИ (Anthropic / OpenAI / совместимые).

Локальные модели
:   Ollama под управлением Студии — модели на вашей машине.

Роль агента
:   Инструкция-персона для агента; встроенные и собственные.

Режим запуска
:   Как установлена Студия: всё-в-одном (контейнер) / контейнеры по отдельности / локальный запуск.
