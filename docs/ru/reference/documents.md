# Документы

<p class="hds-lede">Документ — единица комплекта: у него свой код, свои файлы, свой статус и своя история сборок. Какие документы существуют в вашей работе, объявляет шаблон пака.</p>

Что шаблон объявляет о каждом документе:

- **Код** — короткий шифр на чипе в панели «Документы».
- **Стандарт** — по какому ГОСТ или формату документ собирается; отсюда же берутся правила его проверки.
- **Обязательность** — обязательные документы всегда в комплекте; остальные включаются по смыслу работы.
- **Условия существования** — документ может быть только у командного проекта (общая редакция), только в одном типе работы или только на одном языке.
- **Личный или общий** — в командном проекте общие документы (`shared/`) живут рядом с личными комплектами авторов.

Как документ живёт в проекте:

- **Файлы из шаблона защищены** — их содержимое обновляется из метаданных при сборке, переименовать или удалить их нельзя.
- **Кастомный документ** — любой генерируемый файл можно заменить своим («Заменить на свой файл…»).
- **Метаданные впечатываются при каждой сборке** — незаполненные обязательные поля остаются в PDF жёлтой заливкой <span class="hds-fill">\hseFill</span>.

Работа с документами — в [«Мастерской»](../workbench/documents.md), сборка и лог — [здесь](../workbench/compile.md).
