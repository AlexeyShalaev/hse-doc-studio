# Что уходит в сеть

<p class="hds-lede">Local-first — это проверяемое утверждение, а не лозунг. Ниже — весь список случаев, когда Студия обращается к сети, что именно передаётся и как каждый пункт отключить.</p>

## Всегда локально

Текст ваших работ, метаданные, история изменений, ответы анкет, PNG подписей, собранные PDF — **никогда не покидают машину**, ни при каких настройках. Сборка LaTeX, проверки ГОСТ/ЕСПД и типографики, LanguageTool, конвертация презентаций, редактор ONLYOFFICE — всё выполняется в локальных контейнерах.

## Что и когда ходит в сеть

| Когда | Куда | Что передаётся | Как отключить |
|---|---|---|---|
| Установка и обновление образов | GHCR, Docker Hub | запросы на скачивание образов | не обновляться; образы качаются только по вашей команде (кроме автообновления самой Студии) |
| Проверка обновлений | лента релизов GitHub | версия запрашивается, ничего о вас не отправляется | `HSE_STUDIO__UPDATE_FEED_URL=off` — полный офлайн; выключить автообновление можно в «О программе» |
| **Облачный ИИ-провайдер** (если настроен) | API Anthropic / OpenAI / ваш совместимый | **те фрагменты текста, которые вы отправляете агенту**, и файлы, которые он читает инструментами | не настраивать провайдера — или использовать локальную Ollama: тогда текст не покидает машину |
| Каталог шрифтов | Google Fonts | поисковые запросы каталога; скачивание выбранного шрифта | пользоваться системными шрифтами или загрузкой с устройства |
| **Git-репозиторий** (если вы его подключили) | ваш GitHub, GitLab, Gitea или свой сервер | **вся рабочая история проекта**: тексты, анкеты, подписи, файлы под NDA; токен или ключ для входа. Для своих серверов Студия сначала задаёт короткие запросы «что вы за сервер» без токена, а токен проверяет только у того сервера, для которого он выпущен | не подключать репозиторий; отключить можно в настройках проекта, а целиком выключить функцию переменной `HSE_STUDIO__GIT__ENABLED=false`. Подробности: [Git-синхронизация](../workbench/git-sync.md) |
| «Сотрудник из Вышки» | hse.ru | поисковый запрос по ФИО в открытом справочнике | заполнить руководителя руками |

## Чего нет вовсе

- **Ни телеметрии, ни аналитики, ни crash-репортов.** Никаких счётчиков и маячков ни на сайте, ни в приложении.
- **Ни аккаунтов, ни токенов Студии.** Единственные ключи в системе — ключи ИИ-провайдеров и токены или ключи ssh к вашим git-репозиториям, которые вы сами ввели. Ключи ИИ лежат локально в `ai_providers.json` в вашей папке данных, доступы к git зашифрованы и лежат в `git/` и `secrets/` ([где именно](../workbench/git-sync.md#secrets)); они никуда, кроме соответствующего сервера, не отправляются и не входят в экспорт настроек.

## Полный офлайн

Рабочий сценарий: установить Студию, скачать образ TeX Live первой сборкой, выставить `HSE_STUDIO__UPDATE_FEED_URL=off`, провайдеров не настраивать (или поднять Ollama). После этого сетевой активности нет совсем — писать диплом можно в поезде.

!!! note "Docker-сокет"
    Студия управляет контейнерами через проброшенный `docker.sock` — это доступ уровня
    администратора **к вашей собственной машине**, стандартный приём инструментов такого
    класса. К сети это отношения не имеет, но знать об этом стоит: см.
    [разбор флагов установки](../start/install.md).
