# Раскладка на диске

<p class="hds-lede">У Студии нет базы данных — всё состояние лежит файлами в двух местах: папке данных, которую вы выбрали при первом запуске, и папках проектов. Бэкапите эти папки — бэкапите всё.</p>

## Папка данных

Выбирается в [мастере настройки при первом запуске](../start/first-project.md) (в контейнере видна как `/data`):

```
<папка данных>/
├─ config.json                # настройки приложения (тема, движок, компилятор…)
├─ projects.json              # список проектов (пути, закреплённые, архив)
├─ ai_providers.json          # ИИ-провайдеры (ключи хранятся здесь, локально)
├─ agent_personas.json        # ваши роли агента
├─ update-check.json          # кэш последней проверки обновлений
├─ office-editor-jwt.secret   # секрет для редактора ONLYOFFICE
└─ fonts/                     # управляемые шрифты — монтируются в TeX Live
```

Настройки и провайдеров можно переносить между машинами через Настройки → **Импорт / Экспорт** (в том числе зашифрованным файлом).

## Папка проекта

Каждый проект — самостоятельная папка; путь показан в Настройках проекта:

```
<папка проекта>/
├─ technical_specification/   # папки документов — обычные .tex и ресурсы
├─ thesis/
├─ presentation/
├─ …
├─ .build/<документ>/         # результаты сборки: PDF, .log, .synctex.gz
├─ .hse-studio/               # служебное Студии:
│  ├─ git/                    #   история изменений (отдельный git, не ваш)
│  ├─ history.json            #   журнал документов
│  ├─ forms/                  #   ответы анкет
│  ├─ compiles/  chats/       #   метаданные сборок и чатов агента
│  ├─ submissions/            #   собранные пакеты сдач
│  └─ pdf-archive/            #   PDF прошлых сборок (для «Сравнить»)
└─ project.json               # паспорт проекта: пак, версия, авторы, мета
```

## Правила общежития

- **Файлы документов — ваши.** Редактируйте их чем угодно; Студия заметит внешнюю правку и предложит сравнить.
- **`.hse-studio/` — территория Студии.** Руками туда лучше не ходить; в вашу систему контроля версий её можно не класть.
- **`.build/` пересоздаётся** — можно смело чистить и игнорировать в git.
- **Свой git поверх проекта — пожалуйста.** История Студии живёт изолированно в `.hse-studio/git/` и с вашим репозиторием не конфликтует.

## Что бэкапить

Минимум: **папку данных + папки проектов**. Этого достаточно, чтобы после переустановки (или на новой машине) указать ту же папку данных в мастере — и продолжить с того же места. Образы Docker бэкапить не нужно — они скачаются заново.
