# Общий сервер

<p class="hds-lede">Серверный режим нужен, когда Студией пользуется не один человек: у каждого свой аккаунт, свои проекты, а тяжёлая работа (сборка, упаковка, конвертация) идёт на раннерах. Локальная установка для одного пользователя от этого не меняется.</p>

## Из чего состоит

| Часть | Что делает |
|---|---|
| api | веб-интерфейс, аккаунты, права, очередь задач; одна реплика |
| Postgres | пользователи, сессии, организации, права, настройки, секреты, очередь задач |
| S3 (MinIO, Ceph, AWS) | входные блобы задач, готовые PDF и артефакты; закрытый бакет |
| том проектов | исходники проектов, `projects_root/<id>` |
| раннер | берёт задачи у api по HTTPS, собирает документы в соседних контейнерах |
| LanguageTool, ONLYOFFICE, Ollama | необязательные сервисы |

Redis не нужен: очередь задач работает на Postgres.

## Роли

- **Оператор** разворачивает и обновляет сервер, хранит ключи и бэкапы. Он же оператор персональных данных.
- **Администратор установки** работает в интерфейсе `/admin`: люди, приглашения, вход, почта, раннеры, аудит.
- **Участник проекта** видит только проекты, в которые его добавили. Чужой проект отвечает как несуществующий, а `/admin` для не-админа отвечает 404.
