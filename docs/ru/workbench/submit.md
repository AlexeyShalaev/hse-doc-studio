## Профили сдачи { #checkpoints }

Профиль сдачи — объявленный шаблоном состав пакета: какие документы, анкеты и подписи нужны для конкретной сдачи.

- **Кольцо готовности** «Готово N из M» у каждого профиля; «Закрепить» — и бейджи по всей Мастерской считают блокеры именно к нему.
- **Статусы позиций** — «собран», «не собран», «с ошибками», подписан ли; «Открыть документ» ведёт чинить.
- **«Упаковать»** — архив (zip, tar.gz и другие) с каноническими именами: «Техническое задание.pdf», а не `technical_specification.pdf`; перед упаковкой — преflight-проверки.
- **«Прошлые сборки»** — история пакетов: состав, «Скачать», «Копировать путь».

Состав профилей каждого шаблона — в [справочнике](../reference/checkpoints.md).

## Анкеты { #forms }

Анкеты объявляет шаблон — например, декларацию использования ИИ. Студия рендерит форму, показывает живой предпросмотр и собирает официальный PDF из ваших ответов; статус виден в «Сдаче» и блоке «Сейчас».

## Подписи { #signatures }

- **Библиотека подписей** — по одному PNG на слот (автор, руководитель…) на весь проект; встроенный редактор: «Убрать фон», ластик, обрезка, цвет чернил.
- **Размещение** — перетащите подпись на нужное место страницы документа, при необходимости — дата.
- **Впечатывание** — при упаковке и скачивании «С подписями» PNG впечатывается в PDF; есть и криптографический слой — электронная подпись PAdES сертификатом из настроек.

## Требования { #requirements }

Матрица трассировки: каждое требование из ТЗ (`\req{…}`) и где оно упомянуто (`\reqref{…}`) — статусы «покрыто / не упомянуто» показывают дыры до того, как их найдёт комиссия. Формат распознавания настраивается, «Подобрать с ИИ» предложит его по вашему тексту.

## Командный проект

«Сдача» считает готовность одного автора за раз: выберите, чей пакет собираем, — кольцо, блокеры и архив пересчитаются. Общие документы попадают в пакет каждого автора.
