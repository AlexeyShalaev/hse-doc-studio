# Визуальный редактор

<p class="hds-lede">Редактор работает в двух режимах — «Код» и «Визуальный». Визуальный превращает LaTeX в текст, который выглядит как текст: формулы рендерятся, служебный код сворачивается в карточки. Это тот же файл — переключение мгновенно и без потерь.</p>

## Что умеет

- **Заполнение шаблона** — жёлтые поля <span class="hds-fill">\hseFill</span>, счётчик «Осталось полей: N», ++tab++ ходит по незаполненным; метаданные (тема, руководитель, группа) подставляются при сборке сами.
- **Форматирование** — тулбар: начертания, списки, заголовки, формулы с рендером KaTeX прямо в тексте.
- **Slash-меню** — `/` на пустой строке: рисунок, таблица, ссылка на источник, сноска, разрыв страницы.
- **Картинка из буфера** — ++ctrl+v++ сохраняет файл в проект и вставляет готовый блок рисунка с подписью.
- **Карточки вместо служебного кода** — преамбула, содержание, приложения свёрнуты; титульные листы — «Из шаблона · только чтение», их руками не сломать.
- **Таблицы и источники** — модальные редакторы; библиография — честный `thebibliography` без потерь форматирования.
- **Режим «Код»** — CodeMirror с подсветкой, автодополнением и волнистыми подчёркиваниями замечаний прямо в коде.

Правка того же файла в VS Code не страшна: Студия заметит и предложит «Взять с диска / Оставить своё / Сравнить».
