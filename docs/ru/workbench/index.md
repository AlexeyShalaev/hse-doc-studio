## Что на экране

- **Рейка режимов** — Документы, Замечания, Сдача, Файлы, Настройки, История, Агент; бейджи показывают ошибки, блокеры и ход сборки.
- **Панель** — содержимое выбранного режима; **канвас** — документ: превью, редактор или режим «Рядом».
- **Титлбар** — переключатель проектов (++ctrl+p++), кнопка агента, настройки, версия.
- **Статус-бар** — состояние Docker, движок LaTeX и подсказка про ++ctrl+k++.
- **Палитра команд** ++ctrl+k++ — новый проект, смена темы, агент, прыжки к превью/проверкам/логу, открытие любого проекта.
- **Командный проект** — чипы авторов и общие документы в панели; «Сдача» собирает пакет одного автора за раз.

## Горячие клавиши

| Сочетание | Действие |
|---|---|
| ++ctrl+k++ | Палитра команд |
| ++ctrl+b++ | Свернуть/развернуть панель |
| ++ctrl+j++ | Панель агента |
| ++ctrl+p++ | Переключатель проектов |
| ++ctrl+n++ | Новый проект |
| ++ctrl+comma++ | Настройки |
| ++ctrl+shift+e++ | Документы |
| ++ctrl+shift+m++ | Замечания |
| ++ctrl+shift+f++ | Файлы |
| ++ctrl+shift+d++ | Сдача |
| ++ctrl+shift+b++ | Собрать всё |
| ++slash++ | Фокус в фильтр панели |

На macOS вместо ++ctrl++ — ++cmd++.
