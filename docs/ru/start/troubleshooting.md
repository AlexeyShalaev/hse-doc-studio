# Если не поднялось

<p class="hds-lede">Коротко: симптом → что сделать. Нет вашего случая — <a href="https://github.com/AlexeyShalaev/hse-doc-studio/issues">заведите issue</a>.</p>

- **«Докер не отвечает»** — запустите Docker Desktop (Windows/macOS) или `sudo systemctl start docker` (Linux); для Colima — `colima start` и переменная `DOCKER_SOCK="$HOME/.colima/default/docker.sock"`.
- **Работает, но не собирает ни одного документа** («permission denied» на сокете) — для Docker Desktop достаточно `--group-add 0`; на Linux пересоздайте контейнер с `--group-add "$(stat -c '%g' /var/run/docker.sock)"`. Настройки → Компилятор сами покажут готовую строку.
- **Порт 17240 занят** — скрипт переберёт 17241…17250 сам; вручную поменяйте левую часть `-p`: `-p 18000:8000`.
- **Мастер настройки «вечно ждёт», настройка откатывается** — контейнер запущен без `-e HSE_STUDIO__SERVER__PORT=8000` (на 8000 смотрит HEALTHCHECK): пересоздайте полной командой из [«Установки»](install.md). Либо нет прав на сокет — выполните показанную мастером команду «Запустить вручную».
- **Git Bash ломает пути** (`/var/run/docker.sock` → `C:\Program Files\Git\…`) — префикс `MSYS_NO_PATHCONV=1` или PowerShell.
- **Compose не видит папку проектов** — `DATA_DIR` в `.env` должен быть абсолютным путём, иначе Docker трактует его как имя тома.
- **Первая сборка «висит»** — качается образ TeX Live (≈ 9 ГБ), прогресс во вкладке «Сборка»; это один раз.
- **Мало места на диске** — Настройки → **Диск**: очистка кэша сборки и удаление образов с явным списком.
