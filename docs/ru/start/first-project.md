# Первый проект

<p class="hds-lede">От свежей установки до первого пакета сдачи — на живом примере: Шалаев Алексей Дмитриевич, БПИ222, ФКН НИУ ВШЭ.</p>

1. Откройте <http://localhost:17240> — мастер настройки спросит папку для работ; подойдёт любая, которую вы бэкапите, например `D:/study/hse`.
2. Подтвердите выбор — Студия пересоздаст свой контейнер с этой папкой (соединение на несколько секунд порвётся) и откроет экран «Проекты».
3. Нажмите **«Новый проект»** и выберите пак и шаблон работы — например, ВКР.
4. Возьмите версию шаблона «по умолч.» — она зафиксируется в проекте при создании.
5. Выберите тип работы и язык — от них зависит состав документов.
6. Укажите название, папку проекта и формат презентации (pptx / reveal / beamer).
7. Автор: **Шалаев Алексей Дмитриевич**, группа **БПИ222**, тема работы.
8. Руководитель: кнопка **«Сотрудник из Вышки»** найдёт его на hse.ru и заполнит должность и степень без опечаток.
9. Проверьте сводку и нажмите **«Создать проект»** — до этого момента на диске не появляется ничего.
10. Заполните поля <span class="hds-fill">\hseFill</span> в визуальном редакторе — ++tab++ ведёт по незаполненным.
11. Нажмите **«Собрать всё»** — первый раз дольше обычного (скачивается образ TeX Live, ≈ 9 ГБ), дальше пересборка занимает секунды.
12. Откройте **«Замечания»** нормоконтроля — и упакуйте пакет сдачи на вкладке **«Сдача»**.
