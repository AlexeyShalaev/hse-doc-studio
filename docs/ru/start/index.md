1. **Установите Docker** — единственное требование к машине.
2. **[Установите Студию](install.md)** одной командой — скрипт скачает образ, запустит контейнер и откроет браузер.
3. **[Создайте первый проект](first-project.md)** — мастер настройки спросит папку для работ, мастер проекта доведёт до готового PDF.

## Требования

- **Docker**: Docker Desktop (Windows 10/11 с WSL 2, macOS — Intel и Apple Silicon) или Docker Engine (Linux).
- **Диск**: ≈ 9 ГБ под образ TeX Live (скачивается один раз при первой сборке) плюс сотни мегабайт под саму Студию.
- **Память**: от 2 ГБ ОЗУ и 2 ядер на одну параллельную сборку.
- **Больше ничего**: ни Python, ни LaTeX, ни аккаунта — всё хранится локально, в выбранной вами папке.
