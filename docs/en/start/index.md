1. **Install Docker** — the only machine requirement.
2. **[Install the Studio](install.md)** with one command — the script pulls the image, starts the container and opens the browser.
3. **[Create your first project](first-project.md)** — the setup wizard asks for a work folder, the project wizard takes you to a ready PDF.

## Requirements

- **Docker**: Docker Desktop (Windows 10/11 with WSL 2, macOS — Intel and Apple Silicon) or Docker Engine (Linux).
- **Disk**: ≈ 9 GB for the TeX Live image (downloaded once, at the first build) plus a few hundred megabytes for the Studio itself.
- **Memory**: from 2 GB of RAM and 2 cores per concurrent build.
- **Nothing else**: no Python, no LaTeX, no account — everything stays local, in a folder you choose.
