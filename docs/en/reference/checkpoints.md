# Submission profiles

<p class="hds-lede">A submission profile is a pack-declared point that a package is assembled for: the list of items, the signatures and the forms. It is exactly what the Package button sees.</p>

Profile
:   A named submission point with a description and a list of items. How many there are and which — the template decides; in the app these are the stations of the Submission rail.

Item
:   A document in the package plus its inclusion conditions: “team projects only”, “one track only”, “skipped when NDA is on”. The Studio switches items on and off by the project's properties itself — the conditions are not fine print but the package's logic.

Signature
:   A named slot (author, supervisor…) with one PNG per project and per-document placement. An item may require signatures — without them the readiness ring will not close.

Form
:   A pack-declared questionnaire — an AI-use declaration, for instance. The answers are assembled into an official document of the package.

Readiness ring
:   The “N of M ready” indicator at a point: what is already built, signed and filled in — and what is still missing.

Packaging
:   An archive with canonical file names; every assembled package is kept under Past builds — download it or copy its path.

What it looks like in practice — on the [Submission and packaging](../workbench/submit.md) page.
