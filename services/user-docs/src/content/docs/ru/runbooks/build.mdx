Сборка прогоняет LaTeX по исходникам документа и выдаёт PDF с оглавлением, ссылками и
нумерацией, а заодно запускает проверки оформления. Собирайте документ после заметных правок:
так превью и список замечаний остаются актуальными.

## Если что-то пошло не так

- **«Нет доступных раннеров»**: сейчас нет раннера в сети, который может собрать документ. Когда раннер
  появится, сборка начнётся сама; если его нет несколько минут, сервер снимет сборку и назовёт причину.
- **«Ждём раннер: он на паузе»**: собрать документ может только раннер на паузе (например, ваш личный
  раннер с офисным конвертером). Снимите паузу в «Настройки → Мои раннеры», иначе через 30 минут сервер
  снимет сборку.
- **«Docker не доступен»** в локальной Студии: запустите Docker Desktop и нажмите **Пересобрать**.
- **«Сборка молчит больше 90 секунд»**: процесс, скорее всего, завис. Нажмите **Отменить**, затем
  **Пересобрать**.
- **«Сборка заменена более новой»**: пока сборка ждала, вы запустили ещё одну. Смотрите результат
  новой сборки или нажмите **Собрать заново**.
