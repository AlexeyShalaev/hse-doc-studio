Проект — это папка с исходниками всех документов работы (пояснительная записка, ТЗ, презентация и
другие) и паспортом проекта. Мастер создаёт её из шаблона вашей программы, поэтому оформление,
титульные листы и обязательные разделы уже на месте: остаётся писать текст.

## Если что-то пошло не так

- **«Папка должна быть пустой»** — выберите новую папку или удалите из неё всё лишнее. Студия не
  смешивает свои файлы с чужими.
- **Нет нужного шаблона** — проверьте, что выбран правильный **Пак**. Список шаблонов зависит от пака.
- **«Научный руководитель обязателен для этого шаблона»** — укажите хотя бы ФИО; должность можно
  уточнить позже в настройках проекта.
- **Уже есть папка с проектом** — не создавайте новый, а нажмите **Открыть папку…** на экране
  **Проекты**.
