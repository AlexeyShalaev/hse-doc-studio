Место на сервере занимают журналы, задачи сборок, уведомления и прочие данные со сроком хранения.
Их и так чистит плановая очистка раз в час; **Освободить место** запускает её сразу по всем
источникам. Образы и кэши копятся на машинах раннеров: их чистит сам раннер, а запускаете вы из
окна **Диск**.

<Steps />

## Что входит в «Освободить место»

- Журнал вызовов ИИ, задачи и логи сборок, «Входящие», журнал писем, приглашения и запросы
  доступа, ссылки доступа, гостевые сессии, состояние совместной правки. Каждый источник чистится
  по своему сроку из раздела **Хранение данных**.
- Итог показывает отдельно удалённые записи и освобождённое на диске. Записи, удалённые из таблиц,
  освобождают место внутри базы для новых записей; файлы базы уменьшаются, только когда
  отбрасывается месячная партиция журнала целиком.
- Одновременно идёт одна очистка. Каждый запуск и итог пишутся в журнал аудита.

## Что не входит

- Журнал аудита: вручную не чистится.
- Фоновые уборки: файлы без ссылок, сироты, корзина проектов, просроченные сессии и токены. Они
  идут сами по своему расписанию.
- Диски раннеров: их чистят по одному в окне **Диск**, потому что это отдельные машины.
- Образы на узлах Kubernetes: их удаляет сам Kubernetes, когда на узле мало места.

## Где ещё освободить место

- **Хранение данных**: сроки по каждому источнику и **Очистить сейчас** для одного источника.
- **Раннеры и очередь**: под именем общего раннера ссылка «можно освободить N», если по последнему
  замеру освобождается от 1 ГБ. Что видно в окне **Диск** и что в нём не трогается: [Раннеры
  сборки](/help/ru/admin/runners/#диск-раннера).
- Если раннеры пишут «Обновите раннер, чтобы видеть диск», их версия ниже 0.22.0: обновите их.

## Если что-то пошло не так

- **«Прогон прервался: сервер перезапустился»**: удалённое до этого момента удалено, остальное
  уберёт плановая очистка. Запустите **Освободить место** ещё раз, если нужно сразу.
- **«Не удалось посчитать»** у источника: таблица слишком большая для быстрого счёта. Очистка всё
  равно пройдёт по сроку.
- **«Часть записей удалится при следующей плановой очистке»**: у источника кончился бюджет времени
  на один прогон. Остаток уйдёт в течение часа.
