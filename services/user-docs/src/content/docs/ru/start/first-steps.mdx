HSE Studio помогает оформить документы ВКР, курсовой или Project Proposal по требованиям вашей
программы: шаблон уже содержит титульные листы, обязательные разделы и проверки ГОСТ, а Студия
собирает из исходников готовый PDF. Начните с входа и экрана **Проекты**, остальное открывается
из проекта.

<Steps />

## Если что-то пошло не так

- **«Неверная почта или пароль.»**: проверьте раскладку и регистр. Если пароль забыт, нажмите
  **Забыли пароль?** на экране входа.
- **«Аккаунт ждёт одобрения администратора.»**: вход заработает после одобрения, письмо придёт на
  почту.
- **«Не удалось загрузить проекты»**: сервер не ответил. Проверьте соединение и нажмите
  **Повторить**, ваши проекты на месте.
- **«Docker не доступен»** в локальной Студии: запустите Docker Desktop, без него документы не
  соберутся. Кнопка **Открыть настройки** ведёт к настройкам компилятора.
