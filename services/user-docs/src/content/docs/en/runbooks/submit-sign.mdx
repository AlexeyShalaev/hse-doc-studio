The template of your work describes checkpoints: what to hand in for the pre-defence, the defence
and so on. The **Submission** mode gathers it all in one place: which documents are built, which
forms are filled in, where a signature is missing. The last step, packaging, stamps the signatures
into the PDFs and gives you an archive with the right file names.

## If something goes wrong

- **“This template declares no checkpoints”**: the template does not define a submission set.
  Download the built PDFs from the document previews.
- **“Fill in metadata: …”**: fields are missing before packaging. Fill them in the project
  **Settings** and pack again.
- **“The document is not compiled yet”** on the **Signatures** tab: signatures go onto a built PDF.
  Build the document and come back.
- **“NDA: signatures required”**: the project is under NDA, so the package needs signatures. Add
  them to every slot the checkpoint requires.
