The local Studio installs on your computer as a single Docker container: builds, checks and the
editor work offline, and the files live in a folder you choose. If you also use the cloud Studio,
link the two: the project from the server is downloaded to your computer, your edits flow back to
the server on their own, and built PDFs become visible on the website to your supervisor and
co-authors.

<Steps />

## If something goes wrong

- **“Docker is not running”**: open Docker Desktop, wait until it starts and run the install again.
- **“Docker cannot reach this drive”**: pick a folder in your home directory or allow Docker access to
  the drive in its settings.
- **“The code expired. Start again.”**: click **Sign in to a server** once more and confirm the new
  code within 10 minutes.
- **“Access to the server expired or was revoked. Sign in again.”**: in **Settings** → **Repository
  access** click **Sign in again** next to that server.
