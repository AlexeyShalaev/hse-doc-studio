A build runs LaTeX over the document sources and produces a PDF with the table of contents,
references and numbering, and it also runs the formatting checks. Build after noticeable edits so
the preview and the list of issues stay up to date.

## If something goes wrong

- **“No runners available”**: no build runner is connected to the server right now. Contact the
  server administrator; the build starts by itself once a runner appears.
- **“Docker unavailable”** in the local Studio: start Docker Desktop and click **Rebuild**.
- **“The build has been silent for over 90 seconds”**: the process is most likely stuck. Click
  **Cancel**, then **Rebuild**.
- **“Build replaced by a newer one”**: you started another build while this one was waiting. See
  the result of the newer build or click **Build again**.
- **“Template signature places moved to the new layout: N”**: after a text edit the signature
  lines moved, and the template boxes followed them. Nothing to do. A build does not move manual
  places or documents out for signing.
