A project is a folder with the sources of every document of your work (the report, the
specification, the slides and others) plus the project passport. The wizard creates it from your
programme’s template, so formatting, title pages and required sections are already in place: all
that is left is writing.

## If something goes wrong

- **“The folder must be empty”**: pick a new folder or clear it. Studio does not mix its files with
  anything else.
- **The template you need is missing**: check that the right **Pack** is selected; templates depend
  on the pack.
- **“A supervisor is required for this template”**: enter at least the full name; the title can be
  refined later in the project settings.
- **You already have a project folder**: do not create a new one, click **Open folder…** on the
  **Projects** screen.
