Issues show where the document departs from GOST, ESPD and your programme’s guidelines: margins,
fonts, figure captions, references, typography. Work through them before submission and the
reviewer will not send the work back over formatting.

<Steps />

## If something goes wrong

- **“No issues”** right after opening a project: the checks have not run yet. Build the documents
  to see errors and warnings.
- **“This is a custom document. Some GOST/ESPD checks were skipped”**: the document was uploaded as
  your own file rather than built from the template. Checks tied to the template structure do not
  apply to it.
- **A rule was disabled by mistake**: open the **Rules** tab and click **Enable the rule again** on
  that rule.
- **A requirement is “not mentioned” or “undefined”**: in the first case no other document
  references it with `\reqref`; in the second there is a reference but no `\req` definition in the
  TZ.
