The **Files** section shows the whole project folder: `.tex` sources, the `.bib` bibliography,
figures and appendices. This is also where you upload your own files from your computer: images (PNG,
JPG, SVG), figures and scans in PDF, `.bib`, `.tex` and anything else. Files are stored byte for byte
and the build can use them right away.

<Steps />

## Limits

- One file is at most the server limit (50 MB by default). The Studio refuses a larger file before
  sending it: git hosting services reject files near 100 MB, and the project would stop syncing.
- On a server a project has a space limit. If space runs out, the upload stops and tells you how
  much is left.
- The service folders `.hse-studio`, `.git` and `.build` cannot be uploaded, nor names with `..`.
- Anyone who can edit the project can upload. Readers and reviewers do not see the upload buttons.

## If something goes wrong

- **"The file is larger than …: the server will not accept it"**: make the file smaller (compress
  the PDF or the image) or split the appendix into parts.
- **"Not enough space in the project"**: delete files you do not need or ask the owner to free space.
- **"No write access to this folder"**: in a team project an author writes only to their own folder
  and `shared/`. Ask the owner for the right to edit the whole project.
- **A document is out for signing**: before uploading into its folder the Studio asks you to confirm,
  just as for a normal edit.
