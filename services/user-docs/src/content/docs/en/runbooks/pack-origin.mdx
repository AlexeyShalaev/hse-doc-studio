Template packs reach Studio in two ways. **Built-in** packs ship inside Studio itself: a new version
of such a pack arrives with a Studio update. **Connected** packs come from the pack catalog of the
instance: on a server an administrator connects them (for example, the packs of your department or
university from a git repository), and in a local Studio a pack author connects a folder with the
**Connect to this Studio catalog** button in Template Studio. A new released version of a connected
pack appears without a Studio update.

## What a hidden version means

A hidden version is in Studio, but the new project wizard does not offer it. This happens when:

- an administrator turned off or removed the pack source: the whole pack leaves the wizard;
- the source no longer carries this version (for example, a newer one replaced it);
- a connected pack replaced the built-in one: the built-in versions are hidden and the wizard offers
  the source versions.

Projects already created on a hidden version open and build as before: the version is never removed
or changed. A new project on it cannot be created.

## If something went wrong

- **The pack your classmates use is missing.** Its source may be turned off. Ask the server
  administrator: projects on that pack keep working.
- **The wizard shows a different version than the supervisor’s instructions.** The version may be
  hidden, and the catalog offers a newer one. The project version is in the project settings, the
  “Template version” section.
