Sync keeps the project’s versions in a git repository as well: on GitHub, GitLab, your own server
or a Studio server. That lets two people work on one project, or one person on several computers:
your versions go to the repository and your colleagues’ changes come to you. Studio merges edits
that do not overlap on its own and asks you only about real conflicts.

## If something goes wrong

- **“The repository did not accept the access”**: the token is wrong, revoked or expired. Click
  **Update access** and paste a new token.
- **“The access has no write permission”**: you can read the repository but not send versions. Give
  the token write permission and check again.
- **“The repository holds a different project”**: it cannot be merged with this one. Pick another
  repository or click **Clone into a new folder**.
- **“Set your author name and e-mail first”**: click **Set the author**, fill in the name and e-mail
  and sync again.
