The document source and the finished PDF live on one screen. Write in the visual mode without
thinking about LaTeX commands, or in code when you need a precise edit, and check the layout in
the preview: margins, numbering and formatting look exactly as the reviewer will see them.

## If something goes wrong

- **“SyncTeX unavailable…”**: jumping between the PDF and the source works only after a build.
  Click **Rebuild** and Ctrl/⌘+click again.
- **The preview says “not built”**: the document has not been compiled yet. Click **Build** in
  the document header.
- **“The file changed outside the app while you have unsaved edits”**: the file was changed in
  another editor. Click **Compare**, then **Take from disk** or **Keep mine**.
- **“Failed to load the PDF. Rebuild the document.”**: click **Rebuild**. If the build fails, open
  the **Build** tab and read the log.
