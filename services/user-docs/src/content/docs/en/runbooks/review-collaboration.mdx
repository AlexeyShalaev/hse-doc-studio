On a Studio server a project is visible only to the people it was opened to. The owner decides who
works with the documents and in which role: a co-author edits, a supervisor reads and leaves notes
right on pieces of the text, in the editor or in the PDF preview. Invitations, access requests and replies to comments are collected
in the **Inbox**.

<Steps />

## If something goes wrong

- **“No one found”**: the person must be a user of the server. Invite them with **Invite by email**.
- **“Email is not configured: send the link yourself”**: the server does not send e-mail. Copy the
  **Invitation link** and pass it on any way you like.
- **“The invitation has expired”**: ask the owner for a new one. In the **Pending** card they have a
  **Resend** button.
- **“The fragment was already changed: select it again”**: the text changed while you were writing.
  Select the place once more.
- **“Build the document first”**: you can comment on the preview once the document has a built PDF.
- **“Comment attached to the spot in the PDF”**: the selected text is not in the source (title page, frame,
  an uploaded PDF) or the document was built without SyncTeX. The comment is visible in the preview and in the
  list, but not in the editor.
- **“The spot changed: the PDF was rebuilt”**: after edits the fragment of a PDF comment is no longer found. The
  comment stays in the list, you can reply and resolve it as usual.
