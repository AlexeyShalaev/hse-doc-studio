A runner is your computer or server that builds your projects. Images of earlier Studio versions,
the Docker build cache and project copies pile up on that machine. The runner measures and cleans
them itself, and you decide what to remove.

<Steps />

## What is never removed

- The current version and the previous one kept for rollback (only the box in the confirmation
  removes it).
- Volumes: the TeX Live cache and downloaded models. Without them the next builds take noticeably
  longer.
- Anything that is not the Studio’s: other images and containers on the machine are neither shown
  nor touched.
- Files that running builds need: those builds do not fail.

## If something goes wrong

- **“Update the runner to see its disk”**: a runner older than 0.22.0 cannot report its disk.
  Update it and the disk appears.
- **“The runner is offline”**: you see the last measurement; you can clean up once the runner is
  back.
- **The runner is a desktop Studio**: the window shows only the runner cache. Images on that
  computer are cleaned in the Studio itself: **Settings**, **Disk**.
- **“The runner did not pick up the command within 10 minutes”**: check that the runner is running
  and online, and try again.
