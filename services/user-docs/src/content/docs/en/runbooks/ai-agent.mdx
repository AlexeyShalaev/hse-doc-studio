The agent works directly with the project files: it edits text on request, fixes build errors,
works through GOST issues and rebuilds the document. You see every action it takes and decide what
to keep.

## If something goes wrong

- **The input field says “Select a provider and model…”**: no provider is connected or no model is
  selected. Add a provider in **Tool settings** → **Providers** and pick a **Model**.
- **“The runner didn’t respond. Start it or pick another model.”**: the model runs through your
  runner and it is offline. Start it or click **Pick a model**.
- **“Too many requests to the runner at once, try again in a minute.”**: wait and send the message
  again.
- **The reply stopped with “connection lost”**: send the message again. If that does not help,
  start a **New chat**.
