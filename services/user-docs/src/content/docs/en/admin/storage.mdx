Space on the server is taken by logs, build jobs, notifications and other data with a retention
period. Scheduled cleanup removes it every hour anyway; **Free up space** runs it right away for every
source. Images and caches pile up on runner machines: the runner cleans them itself, and you start
it from the **Disk** window.

<Steps />

## What “Free up space” covers

- The AI call log, build jobs and logs, the inbox, the mail log, invitations and access requests,
  share links, guest sessions and the co-editing state. Every source is cleaned by its own period
  from **Data retention**.
- The result shows deleted records and space freed on disk separately. Records deleted from tables
  free space inside the database for new records; database files shrink only when a whole monthly log
  partition is dropped.
- One cleanup runs at a time. Every start and result goes to the audit log.

## What it leaves out

- The audit log: it is never cleaned manually.
- Background cleanups: unreferenced files, orphans, the project bin, expired sessions and tokens.
  They run on their own schedule.
- Runner disks: they are cleaned one at a time in the **Disk** window, because they are separate
  machines.
- Images on Kubernetes nodes: Kubernetes removes them itself when a node runs low on space.

## Where else to free up space

- **Data retention**: the period of every source and **Clean now** for a single source.
- **Runners and queue**: under a shared runner's name a link “N can be freed” appears when the last
  measurement can free 1 GB or more. What the **Disk** window shows and what it never touches:
  [Connect build runners](/help/en/admin/runners/#runner-disk).
- If runners say “Update the runner to see its disk”, their version is below 0.22.0: update them.

## If something goes wrong

- **“The run was interrupted: the server restarted”**: what was deleted before that is gone,
  scheduled cleanup removes the rest. Run **Free up space** again if you need it now.
- **“Could not count”** for a source: the table is too large for a quick count. The cleanup still
  goes by the period.
- **“Some records will be deleted by the next scheduled cleanup”**: the source ran out of its time
  budget for one run. The rest goes within an hour.
