# hse-doc-studio Web Application

Frontend для hse-doc-studio. React, TypeScript, Feature-Sliced Design.

## Features

- **Feature-Sliced Design**: Scalable architecture.
- **Strict Type Safety**: TypeScript 5.8+ strict.
- **Modern State Management**: TanStack Query, Zustand, nuqs.
- **Accessible UI**: Radix UI primitives.
- **Internationalization**: RU / EN.

## Setup

1. Install dependencies:
    ```bash
    make install
    ```
2. Start development server:
    ```bash
    make dev
    ```

## Development

- `make fmt`: Format and lint.
- `make test`: Run tests with coverage.
- `make typecheck`: TypeScript checks.
- `make build`: Production build.
